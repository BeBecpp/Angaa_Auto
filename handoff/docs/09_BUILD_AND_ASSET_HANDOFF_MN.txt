АНГАА АВТО — CLAUDE CODE BUILD, LOCAL БА SERVER ЗААВАР

1. АЖЛЫН ХАВТАС
Шинэ work folder үүсгээд ZIP-ийн ANGAA_AUTO хавтсыг дотор нь handoff гэж нэрлэж тавина. Claude Code work folder дээрээс ажиллана. Laravel app/ гэсэн шинэ хоосон target-д үүснэ; handoff/ нь source specification/assets хэвээр хадгалагдана.

Ubuntu/Xubuntu/Bash жишээ (download замыг өөрийнхөөрөө солино):
mkdir -p ~/Projects/angaa-auto-work
cp -R /path/to/ANGAA_AUTO ~/Projects/angaa-auto-work/handoff
cd ~/Projects/angaa-auto-work
claude

PowerShell жишээ:
New-Item -ItemType Directory -Path "$env:USERPROFILE\Projects\angaa-auto-work" -Force
Copy-Item -LiteralPath "C:\path\ANGAA_AUTO" -Destination "$env:USERPROFILE\Projects\angaa-auto-work\handoff" -Recurse
Set-Location "$env:USERPROFILE\Projects\angaa-auto-work"
claude

Эдгээр нь Claude Code CLI өмнө суусан нөхцөлд. Өөр орчинд энэ folder-ийг Open Folder-оор нээнэ. Existing project-той холихгүй, шинэ work folder сонго. ZIP root нь npm/composer application биш.

3. SCAFFOLD — CLAUDE ХИЙНЭ
Work root дээр, app/ target өмнө байхгүй үед:
composer create-project laravel/laravel app "^13.0"
cd app
composer require filament/filament:"^5.0"
php artisan filament:install --panels
Эдгээр нь scaffold; бүрэн application биш. Livewire4/Tailwind4.1+ ба бусад dependency-ийг actual Composer/npm resolution, official docs, lockfiles-оор батална. PowerShell constraint дамжуулах асуудал байвал Filament official Windows guidance хэрэглэнэ.
app/ өмнө үүссэн бол дахин scaffold хийж дарж бичихгүй; code ба app/PROGRESS.md-ээс үргэлжлүүлнэ.

6. LOCAL АЖИЛЛУУЛАХ — APPLICATION БЭЛЭН БОЛСНЫ ДАРАА
app/ дотор composer/npm dependencies, .env, SQLite file, APP_KEY, migrations, guarded demo seed-ийг project README-ийн баталгаажсан алхмаар эхлээд тохируулна. Дараа тус тусдаа process:
php artisan serve
npm run dev
php artisan queue:work --tries=3
php artisan schedule:work
Browser дээр бодитоор хэвлэгдсэн local URL-ийг нээнэ. Production-д artisan serve/Vite dev ашиглахгүй.
Queue/scheduler эсвэл компьютер зогсвол timed reminder ажиллахгүй. SMS log driver нь simulated; бодитоор очсон гэж харагдуулахгүй. OTP local viewer нь local/testing ба тухайн challenge/session-д хязгаарлагдана; universal code байж болохгүй.
app:demo-seed, app:owner-create, reminders:dispatch --dry-run, app:readiness нь Claude ХЭРЭГЖҮҮЛЭХ custom command; Laravel-д угаасаа байгаа гэж үзэхгүй.

7. БҮТЭН DEMO-Г ХҮЛЭЭЖ АВАХ
Photo request → Ангаа цаг батлах → механик intake/км/онош/зураг → estimate → customer approval → repair/QC → partial+final manual payment → delivery → private history → due date/km → dry-run reminder → rebook.

Бодит SMS provider сонгосны дараа current verified API contract-аар adapter хийнэ; кирилл segmentation, оператор бүрийн accepted/delivered state test. Provider accepted нь delivered биш. QPay/ebarimt нь дараагийн бодит integration; fake success endpoint үүсгэхгүй.
